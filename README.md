# 自动记账（AutoLedger）

一款安卓本地自动记账 App：监听微信 / 支付宝的支付通知，自动提取金额、商户、时间，存进手机本地。

**不联网上传任何账单数据、不上架任何应用商店，只在你自己的手机上运行。**

## 二、装完必做（不做等于白装）

自动记账依赖系统的「通知读取权限」，装完**必须手动开一次**才能生效：

1. 打开 App → 底部「**我的**」→「**通知读取权限**」→ 在系统列表里找到「自动记账 · 支付通知读取」并打开。
2. **电池优化白名单**：设为「不限制 / 允许后台运行」（否则后台容易被系统杀掉，就收不到通知了）。
3. **自启动**：应用详情里打开「自启动 / 关联启动 / 后台弹窗」。
4. 用微信或支付宝真实付一笔小额（如 0.01 元），回 App 看是否自动出现一条记录。

> **不同手机品牌**：
> - 小米/红米：安全中心 → 应用管理 → 自动记账 → 省电策略选「无限制」，并在最近任务里给 App 上锁。
> - 华为/荣耀：应用启动管理里关掉「自动管理」，手动打开三个开关。
> - OPPO/vivo：允许「后台运行」「自启动」「关联启动」。

## 三、⚠️ 注意事项（重要，请先看）

### 1. 关于「读取通知」这个权限

本 App 的核心功能依赖系统的**「通知使用权」**，这是一个**比较敏感的权限**：

- 开启后，App 能读到手机上所有 App 弹出的通知内容（不止微信/支付宝）。
- 所以系统授权时会弹出**醒目的警告**，这是正常现象，不是 App 有问题。
- **App 实际只处理你勾选的微信 / 支付宝，且只提取其中有金额的支付通知**，其余通知一律忽略、不记录、不存储。
- **所有数据只存在你手机本地，不上传任何服务器**；App 也不申请短信、联系人、定位、相机等权限。

> 一句话：这个权限确实敏感，但 App 只用它做「自动记账」这一件事，数据完全本地。如果你介意"读通知"这个动作本身，那就不适合用通知监听类记账方案。

### 2. 关于隐私

- 账目数据全部存在你手机本地，卸载即清空，**没有云同步、没有账号体系**。
- App 只在「检查新版本」时联网读一下版本号（一个只读的小请求），**不包含任何个人信息**。

### 3. 已知边界

- 如果支付通知里本身没有金额（例如只写「你有一笔新的收款」），那就无法自动记，需要手动补记。
- 微信/支付宝更新通知格式后，个别情况可能需要调整识别规则，这是该方案的固有成本。

## 四、主要功能

- **自动记账**：监听微信/支付宝支付通知，自动入账（金额、商户、时间）。
- **手动记一笔**：自绘数字键盘 + 分类图标，随手记。
- **识图记账**：导入账单截图，本地离线 OCR 识别，勾选确认后批量入账。
- **桌面小组件**：2×2 小组件显示今日支出/收入，点「+」直接记一笔。
- **统计报表**：环形占比图、日历视图、月度汇总、柱状图。
- **检查更新**：打开 App 自动检查新版本，提示下载。
